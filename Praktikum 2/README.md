## Cara Kerja Coding
Aplikasi membuat berita menggunakan Flow.
Berita baru muncul setiap 2 detik.
Data disimpan dengan StateFlow agar tampilan otomatis berubah.
Pengguna dapat memilih kategori berita.
Saat berita dipilih, Coroutine mengambil detail berita secara asynchronous.
